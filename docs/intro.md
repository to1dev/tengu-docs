# 认识 Tengu

Tengu 是一款以本地运行为核心的加密资产桌面客户端。它希望把钱包、链上数据、脚本与分析工具放进同一个工作环境，让你在自己的设备上管理数据、理解操作并掌握密钥。

桌面界面和本地计算由 C++ / Qt 实现。查询余额、获取行情或广播交易仍需要连接相应网络；本地运行不等于所有功能都能离线使用。

## 版本与功能边界

本站以 `0.0.1-alpha (Reforge)` 为基准，发布日期为 2025-04-30，提供 Windows x64 安装包。源码仓库可能有后续开发提交，不能直接等同于已发布版本。

多链交易、行情分析、自动化策略、AI、P2P 分发与 NFT 授权是项目的设计方向。具体可用功能以你安装版本的界面和发布说明为准；[白皮书](/whitepaper)中的规划不构成交付承诺。
