# 开源与商业授权

Tengu 采用双重许可：开源版本适用 AGPLv3；需要额外的闭源分发、再授权或协议约定的支持权益时，可取得商业许可。

## 如何选择

| 使用方式 | 阅读入口 |
| --- | --- |
| 使用、研究、修改开源版本，履行许可义务 | [AGPLv3 说明](/license/agplv3) |
| 获取协议约定的额外商业权利 | [商业条款（中文）](/license/commercial-zh) / [Commercial terms](/license/commercial) |
| 通过被认可的 NFT 取得 Tier 2 权利 | [NFT 授权说明](/license/nft) |

**商业使用不自动等于必须购买许可。** AGPLv3 允许商业使用，关键是能否遵守相应的分发、源代码和网络交互义务。额外商业许可适用于希望取得 AGPLv3 之外权利的场景。

## 等级与升级

| 等级 | 费用 | 范围概览 |
| --- | --- | --- |
| Tier 1 | 免费，AGPLv3 | 按开源许可使用、修改与分发 |
| Tier 2 | 1 SOL 或有效授权 NFT | 协议约定的商业使用、修改和分发 |
| Tier 3 | 5 SOL 或等值 TENGU | Tier 2 权利及额外再授权、集成权利 |
| Tier 4 | 50 SOL 或等值 TENGU | Tier 3 权利及约定的优先支持和高级权益 |

升级按等级差额计算：Tier 2 → Tier 3 为 4 SOL，Tier 2 → Tier 4 为 49 SOL，Tier 3 → Tier 4 为 45 SOL。支付方式、凭证、生效与终止条件以商业协议为准。

## NFT 与授权凭证

有效且被项目认可的 NFT 可作为 Tier 2 资格依据。需要完成持有验证和协议规定的授权密钥发放；不能把市场上同名 NFT 直接当作有效授权。

奖励、空投和高级模块依可用性与单独公告安排，没有固定时间、金额或收益保证。第三方组件始终保留各自许可，不因 Tengu 商业授权而自动获得豁免。

咨询授权范围、发行状态或合作方案，请联系 [tengu@to1.dev](mailto:tengu@to1.dev)。
