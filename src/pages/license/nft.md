# NFT 授权说明

Tengu 的授权设计允许被项目认可的有效 NFT 作为 Tier 2 资格凭证。NFT 是授权依据之一，其实际权利由[商业协议](/license/commercial-zh)定义，不能单凭名称、图片或市场描述判断。

## 权利与边界

完成协议要求的持有验证和授权凭证发放后，可取得 Tier 2 所约定的使用、修改与分发权利。再授权、优先支持和其他高级权益需匹配相应等级，不能把一枚 Tier 2 NFT 理解为 Tier 2–4 的全部权利。

商业许可仅覆盖协议约定的 Tengu 代码。第三方依赖、品牌与其他材料按各自适用的许可和授权范围处理。

奖励、空投、优先测试与高级模块依可用性和单独公告安排，不保证年度分发、具体金额、交付时间或资产价值。

## 验证流程

1. 核对项目公布或书面认可的集合、合约与 NFT 标识。
2. 按正式流程证明钱包持有权，验证只需要相应公开信息和证明，不应要求提供私钥或助记词。
3. 完成商业协议规定的授权密钥发放，核对等级与生效条件。
4. 保留授权凭证和相关通知，便于后续升级或转让。

链上查询需要可用节点。NFT 授权是设计机制，不代表任意 Alpha 版本已经支持自动激活。

## 转让与升级

按商业协议，NFT 对应的 Tier 2 资格随有效转让移交，新持有者仍需完成验证和授权凭证更新。原持有者不再凭该 NFT 享有相应资格。

以 Tier 2 为基础升级至 Tier 3 的差额为 4 SOL，升级至 Tier 4 为 49 SOL；具体支付、凭证和终止条件见[商业条款](/license/commercial-zh)。
