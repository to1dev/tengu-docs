# 项目与联系

Tengu 关注本地计算、数据自主与可扩展的桌面工作环境。这里汇集使用指南、设计说明和作者文章，帮助你了解项目的方向与边界。

## 项目入口

- [认识 Tengu](/docs/intro)：了解定位与 Alpha 版本状态。
- [下载与安装](/docs/quickstart)：核对发布记录和校验文件。
- [设计白皮书](/whitepaper)：查看架构方向与路线图。
- [授权说明](/license/dual_license)：区分开源许可与额外商业权利。
- [作者博客](/blog)：了解项目背后的思考。
- [源码仓库](https://github.com/to1dev/tengu)：以可访问的目标提交为准。

## 联系与反馈

使用问题、商业授权或合作咨询可发送至 [tengu@to1.dev](mailto:tengu@to1.dev)。也可以加入 [Telegram](https://t.me/TenguAI) 或 [Discord](https://discord.gg/vFYFjdtFbn)。

报告问题时提供版本、系统与复现步骤，详见[故障排查](/docs/basics/congratulations)。请勿发送私钥、助记词、钱包密码或未经脱敏的账户资料。
